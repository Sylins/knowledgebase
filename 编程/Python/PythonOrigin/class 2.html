第2章：print() 函数——彻底理解

上一章我们只用了 print("Hello, World!")，但 print() 能做的事情远不止这么简单。这一章我们把这个函数彻底拆解明白。

2.1 函数是什么——先理解这个概念

在讲 print() 之前，必须先搞懂函数是什么。

函数的本质：一段有名字的代码，你叫它的名字，它就执行那段代码。

打个比方：

你有一个机器人，你对它说"扫地"，它就开始执行扫地的动作。"扫地"就是函数名，你喊"扫地"就是在调用函数。

在 Python 中：

print("你好")
你好
  • print → 函数的名字
  • () → 调用运算符，意思是"执行这个函数"
  • "你好" → 传给函数的参数，告诉函数具体要做什么

关键区别：

print       # 这是函数对象本身，不会执行，只是引用这个函数
print()     # 这是调用函数，会执行，但没传参数
print("Hi") # 这是调用函数并传递参数 "Hi"


Hi

你可以验证：

>>> print
<built-in function print>

print 不带括号时，Python 告诉你它是什么东西（一个内建函数），而不会执行它。

2.2 print() 的参数结构

print() 的完整签名（定义）是这样的：

print(*objects, sep=' ', end='\n', file=None, flush=False)

我们现在逐一拆解。

参数一：*objects —— 要打印的内容

星号 * 的意思是：可以接收任意多个参数。

print("苹果")
print("苹果", "香蕉")
print("苹果", "香蕉", "橘子")
print(1, 2, 3, 4, 5, 6, 7, 8)
苹果
苹果 香蕉
苹果 香蕉 橘子
1 2 3 4 5 6 7 8

你可以传1个、2个、100个参数，print() 会依次打印它们。

"参数"和"参数之间用逗号分隔"这个动作本身，也是语法的一部分：

print("苹果", "香蕉", "橘子")
苹果 香蕉 橘子

Python 解释器读这行代码时的思考过程：

看到 print → 函数名
看到 ( → 进入参数收集模式
看到 "苹果" → 第一个参数，是一个字符串
看到 , → 参数分隔符，说明后面还有参数
看到 "香蕉" → 第二个参数
看到 , → 参数分隔符
看到 "橘子" → 第三个参数
看到 ) → 参数收集结束，共收集到3个参数
开始调用 print，传入这3个参数

参数二：sep=' ' —— 分隔符

sep 是 separator（分隔符）的缩写。

默认值是一个空格 ' '。

这意味着，当你传多个参数时，print() 会在每两个参数之间插入一个空格：

print("苹果", "香蕉", "橘子")
苹果 香蕉 橘子

"苹果" 和 "香蕉" 之间自动插入了一个空格，"香蕉" 和 "橘子" 之间也插入了一个空格。

修改 sep：

print("苹果", "香蕉", "橘子", sep=" | ")
苹果 | 香蕉 | 橘子
print("苹果", "香蕉", "橘子", sep="")
苹果香蕉橘子
print("2024", "01", "15", sep="-")
2024-01-15
print("A", "B", "C", sep=" -> ")
A -> B -> C

sep 只在有多个参数时才有意义。如果只有一个参数，没什么需要分隔的，sep 不起作用：

print("Hello", sep="---")
Hello

sep 没派上用场

参数三：end='\n' —— 结束符

end 是每次打印结束后自动追加的内容。

默认值是换行符 \n。

什么叫换行符？

计算机中，有些字符是"不可见字符"，它们不代表任何可以显示的图形，而是代表一个控制指令。

  • \n → newline，换行。让光标移到下一行的开头
  • \t → tab，制表符。相当于按一下 Tab 键
  • \\ → 反斜杠本身
  • \" → 双引号（在字符串内部使用）

当你写：

print("第一行")
print("第二行")
第一行
第二行

实际发生的事：

输出 "第一行"
输出 "\n"    （end 的默认值）
输出 "第二行"
输出 "\n"

所以屏幕上显示：

第一行
第二行

光标现在停在第三行的开头（因为最后又输出了一次 \n）。

修改 end：

print("Hello", end="")
print("World")
#（第一行末尾没有换行，第二行紧跟着输出）
HelloWorld
print("加载中", end="...")
print("完成！")
加载中...完成！
print("A", end=" -> ")
print("B", end=" -> ")
print("C")
A -> B -> C

end 每次 print 都会生效，不管传了几个参数：

print("苹果", "香蕉", end="【结束】\n")
print("橘子")
苹果 香蕉【结束】
橘子

参数四和五：file 和 flush

这两个参数暂时不讲，因为它们涉及文件操作和输出缓冲，放在文件操作章节详细展开。

简单说：

  • file 可以让你把输出写入文件而不是屏幕
  • flush 控制是否立即刷新输出缓冲区

现在你只需要知道它们存在，默认情况下不需要管。

2.3 print 的完整实验

我们来做一个实验，把所有参数组合起来：

print("A", "B", "C", sep=" | ", end=" <<<END>>>\n")
print("D", "E", sep=" + ", end="\n\n")
print("结束")
A | B | C <<<END>>>
D + E

结束

逐行分析：

第一行 print("A", "B", "C", sep=" | ", end=" <<<END>>>\n")：

  • 三个参数："A"、"B"、"C"
  • sep=" | " → 参数间用 " | " 分隔
  • 打印内容：A | B | C
  • end=" <<<END>>>\n" → 末尾追加 " <<<END>>>" 然后换行

第二行 print("D", "E", sep=" + ", end="\n\n")：

  • 两个参数："D"、"E"
  • sep=" + " → 参数间用 " + " 分隔
  • 打印内容：D + E
  • end="\n\n" → 末尾追加两个换行符，产生一个空行

第三行 print("结束")：

  • 正常打印 "结束" 后换行

2.4 print 打印不同类型的数据

print() 可以打印任何类型的数据：

print(123)           # 整数
print(3.14)          # 浮点数
print(True)          # 布尔值
print(None)          # None
print([1, 2, 3])     # 列表
123
3.14
True
None
[1, 2, 3]

print 内部做了什么事？ 它调用了每个参数的 __str__() 方法，把参数转换成字符串再输出。

所以 print(123) 实际上等价于 print(str(123))。

你可以验证：

print(123)
print(str(123))
123
123

两行输出完全一样。

2.5 print 的返回值

print() 是一个函数，函数都有返回值。

result = print("Hello")
print(result)
Hello
None

print() 的返回值是 None。

第一行：print("Hello") 执行，屏幕显示 "Hello"，然后返回 None，None 被赋值给 result。

第二行：print(result) 就是 print(None)，屏幕显示 "None"。

这是一个常见的混淆点：

print("Hello")      # 打印了 Hello，返回值是 None
x = print("Hello")  # 打印了 Hello，但 x 的值是 None，不是 "Hello"

2.6 常见错误

错误一：忘记逗号，用空格分隔参数

print("苹果" "香蕉" "橘子")
苹果香蕉橘子

相邻的两个字符串字面量会被 Python 自动拼接。这不是 print() 的功能，是 Python 的字符串字面量拼接规则。

这等价于：

print("苹果香蕉橘子")
苹果香蕉橘子

三个字符串在代码执行前就合成一个了，不是 print 的作用。

如果你想在 print 中传多个参数，必须用逗号：

print("苹果", "香蕉", "橘子")    # 正确，三个参数
print("苹果" "香蕉" "橘子")      # 错误理解，这只是一个参数
苹果 香蕉 橘子
苹果香蕉橘子

错误二：变量用引号括起来

name = "小明"
print("name")    # 输出 name，不是小明
print(name)      # 输出 小明

name
小明

加了引号就是字符串，没加引号就是变量。

错误三：用 + 拼接不同类型

age = 18
print("我今年" + age + "岁")    
# 报错！字符串和整数不能相加
Traceback (most recent call last):
  File "wrong_age.py", line 2, in <module>
    print("我今年" + age + "岁")    # 报错！字符串和整数不能相加
          ~~~~~~~~~^~~~~
TypeError: can only concatenate str (not "int") to str

解决方法：

age = 18
print("我今年" + str(age) + "岁")    # 先转换类型
print("我今年", age, "岁")           # 用逗号分隔，自动加空格
print(f"我今年{age}岁")              # 用 f-string（后面会讲）

我今年18岁
我今年 18 岁
我今年18岁

2.7 本章总结

概念 说明
函数调用 函数名 + 括号 + 参数，如 print("Hi")
*objects 可以传任意多个参数，用逗号分隔
sep 参数间的分隔符，默认是空格 ' '
end 末尾追加的内容，默认是换行 '\n'
\n 换行符，光标移到下一行开头
print() 返回值 总是 None
不加引号 Python 会当变量名处理
加引号 Python 会当字符串字面量处理
