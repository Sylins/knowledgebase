第1章：Python 是什么？怎么运行第一行代码？

1.1 Python 的本质

你写的代码，计算机看不懂。计算机只认识一种东西：机器指令，就是一串二进制的数字。

比如，在某个芯片上，这串数字：

10110000 01100001

可能表示"把数字 97 放进某个寄存器"。

人类显然没法直接用这种方式写程序。于是人们发明了编程语言，作为人和计算机之间的翻译官。

Python 就是这个翻译官之一。

当你运行 Python 程序时，发生的事情是这样的：

你写的代码（.py 文件）
↓
Python 解释器读取代码
↓
解释器把代码翻译成字节码（.pyc）
↓
Python 虚拟机执行字节码
↓
计算机硬件执行操作

关键理解：你写的 .py 文件本身不会被执行，它只是文本。是 Python 解释器这个程序读取它、理解它、然后代你操作计算机。

1.2 什么是"解释型语言"

编程语言分为两大阵营：

编译型（C、C++、Rust、Go）：

源代码 → 编译器 → 可执行文件(.exe) → 用户直接双击运行
  • 编译是一次性的，生成的可执行文件可以脱离编译器独立运行
  • 运行速度快，因为已经是机器码了
  • 但修改代码后必须重新编译

解释型（Python、JavaScript、Ruby）：

源代码 → 解释器 → 一行一行地边翻译边执行
  • 没有独立的可执行文件，必须通过解释器运行
  • 每次运行都要经过解释器
  • 好处是：改了代码立刻就能跑，不用编译

Python 的灰色地带：Python 实际上会先把你的代码编译成"字节码"（.pyc 文件），然后在 Python 虚拟机上执行字节码。这和 Java 很像。所以 Python 不是"纯解释型"，它有一个隐式的编译步骤，但这个过程对你是透明的，你感受不到。

1.3 为什么选择 Python 作为第一门语言

对比 C 语言的 Hello World：

#include <stdio.h>

int main() {
printf("Hello, World!\n");
return 0;
}
Hello, World!

你需要理解：

  • #include 是什么（预处理器指令）
  • <stdio.h> 是什么（标准输入输出头文件）
  • 为什么有一个 main 函数
  • int 是什么（返回值类型）
  • \n 是什么（转义字符）
  • return 0 是干什么的

而 Python：

print("Hello, World!")
Hello, World!

你只需要理解一件事：print 是"打印"的意思。

这就是 Python 设计哲学的核心：代码是写给人看的，顺便让计算机执行。

1.4 安装 Python——到底安装了什么

当你从 python.org 下载安装包并安装后，你的计算机上多了几样东西：

1. Python 解释器

  • 这是一个可执行文件，Windows 上叫 python.exe
  • 它的作用就是读取 .py 文件并执行
  • 位置通常在 C:\Users\你的用户名\AppData\Local\Programs\Python\Python312\

2. pip（包管理工具）

  • pip 是 Python 的"应用商店"
  • 用来下载别人写好的代码库（比如数据科学用的 numpy、pandas）
  • 命令：pip install 包名

3. IDLE（简易编辑器）

  • Python 自带的代码编辑器
  • 可以用，但不推荐，因为它功能太简陋了

4. 标准库

  • Python 自带的"工具箱"，包含处理文件、网络、日期等各种功能的模块
  • 你不用安装任何东西就能用它们

1.5 PATH 环境变量——为什么必须勾选"Add Python to PATH"

这是安装 Python 时最容易出错的地方。

问题：当你打开命令行输入 python，计算机怎么知道 python.exe 在哪里？

答案：计算机会去一个叫 PATH 的列表里挨个找。

PATH 就是一系列文件夹路径：

C:\Windows\System32
C:\Windows
C:\Program Files\...

当你在命令行输入一个命令，操作系统会：

  1. 先去当前文件夹找这个命令
  2. 如果找不到，去 PATH 列表里的每个文件夹按顺序找
  3. 全找不到，就报错：'python' 不是内部或外部命令

如果你没勾选 "Add Python to PATH"，Python 的安装目录就不在 PATH 里，命令行就找不到 python。

解决方案：

  • 重新安装 Python 并勾选
  • 或者手动把 Python 路径加到系统环境变量里

1.6 第一个程序——逐字节拆解

创建文件 hello.py，内容：

print("Hello, World!")
Hello, World!

现在我们来拆解这行代码的每一个字符：

字符 含义
p函数名的第一个字母
r函数名的第二个字母
i函数名的第三个字母
n函数名的第四个字母
t函数名的第五个字母
(左括号：告诉 Python "我要调用函数了，下面是参数"
"双引号：告诉 Python "下面是一个字符串的开始"
H字符串的第一个字符
e字符串的第二个字符
l字符串的第三个字符
l字符串的第四个字符
o字符串的第五个字符
,字符串中的逗号字符
空格字符
W字符串的第八个字符
o字符串的第九个字符
r字符串的第十个字符
l字符串的第十一个字符
d字符串的第十二个字符
!感叹号字符
"双引号：告诉 Python "字符串到此结束"
)右括号：告诉 Python "参数结束"

Python 读这行代码时的思考过程：

看到 print → 这是函数名
看到 ( → 开始收集参数
看到 " → 开始读取字符串
看到 H, e, l, l, o, ,,  , W, o, r, l, d, ! → 这是字符串的内容
看到 " → 字符串结束，得到一个字符串 "Hello, World!"
看到 ) → 参数收集完毕，参数是 "Hello, World!"
开始调用 print 函数，把 "Hello, World!" 传给它
print 函数把内容输出到屏幕

1.7 运行程序的三种方式

方式一：命令行运行

python hello.py

逐步骤解释：

  1. python → 操作系统在 PATH 中找到 python.exe
  2. hello.py → 告诉 Python 解释器要执行这个文件
  3. Python 解释器打开 hello.py，读取全部内容
  4. 逐行执行代码
  5. 执行完毕，Python 解释器退出

方式二：交互式模式（REPL）

在命令行直接输入 python（不带文件名），会进入交互模式：

>>> print("Hello")
Hello
>>> 1 + 1
2
>>> exit()
  • >>> 是提示符，表示 Python 在等你输入
  • 你输入一行代码，回车，Python 立即执行并显示结果
  • 适合快速测试小段代码
  • 输入 exit() 或按 Ctrl+Z（Windows）退出

方式三：在 VS Code 等编辑器里运行

VS Code 装上 Python 插件后，右上角有一个运行按钮（▶），点一下就运行。

本质上，VS Code 也是帮你执行了 python 你的文件名.py 这个命令，只是把过程图形化了。

1.8 如果出错了怎么办——你的第一个 bug

假设你不小心写成了：

print("Hello)

运行会报错：

  File "hello.py", line 1
    print("Hello)
          ^
SyntaxError: unterminated string literal (detected at line 1)

逐词翻译这个错误信息：

英文 中文 含义
File "hello.py"文件 "hello.py"错误发生在哪个文件
line 1第1行错误发生在第几行
print("Hello)出错的代码
^小箭头指向出错的大概位置
SyntaxError语法错误错误类型：代码不符合 Python 语法
unterminated string literal未结束的字符串字面量具体原因：字符串没有用引号正确关闭

这个错误信息已经告诉你了：

  • 在哪里出错了（第1行）
  • 是什么错误（语法错误）
  • 具体原因（字符串没关引号）

学习看错误信息是编程最重要的技能之一。 每次报错，先不要慌，仔细读错误信息的最后一行，它通常会告诉你问题出在哪。
