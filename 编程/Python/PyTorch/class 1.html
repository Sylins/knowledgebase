第1课：张量的创建与基本属性

1.1 张量是什么

张量是 PyTorch 中最基本的数据结构。你可以这样理解：

  • 标量是 0 维张量（一个数）
  • 向量是 1 维张量（一维数组）
  • 矩阵是 2 维张量（二维数组）
  • 三维及以上统称为高维张量（如一批图片：batch × 通道 × 高 × 宽）

在 PyTorch 中，所有数据（输入、输出、权重、梯度）都以张量形式存在。

1.2 从 Python 列表或 NumPy 数组创建张量

这是最直接的创建方式，适合将已有数据转为张量。

import torch
import numpy as np

# 从 Python 列表创建
a = torch.tensor([1, 2, 3])
print(a)                    # tensor([1, 2, 3])
print(type(a))              # <class 'torch.Tensor'>

# 从嵌套列表创建二维张量
b = torch.tensor([[1, 2], [3, 4]])
print(b)
# tensor([[1, 2],
#         [3, 4]])

# 从 NumPy 数组创建（共享内存，修改一方会影响另一方）
np_arr = np.array([5, 6, 7])
c = torch.from_numpy(np_arr)
print(c)                    # tensor([5, 6, 7])

# 修改 NumPy 数组，张量也会跟着变（反之亦然）
np_arr[0] = 100
print(c)                    # tensor([100, 6, 7])
tensor([1, 2, 3])
<class 'torch.Tensor'>
tensor([[1, 2],
        [3, 4]])
tensor([5, 6, 7])
tensor([100,   6,   7])

关键点：torch.tensor() 和 torch.from_numpy() 的区别：

  • torch.tensor() 会复制数据，创建独立的张量
  • torch.from_numpy() 共享内存，更高效但需注意副作用

1.3 使用内置函数创建特殊张量

深度学习中经常需要初始化特定值的张量，这些函数必须熟记。

# 全零张量
zeros = torch.zeros(2, 3)           # 形状 2行3列，全部为0
print(zeros)
# tensor([[0., 0., 0.],
#         [0., 0., 0.]])

# 全一张量
ones = torch.ones(2, 3)             # 形状 2行3列，全部为1

# 单位矩阵（对角线为1，其余为0）
eye = torch.eye(3)                  # 3x3 单位矩阵
# tensor([[1., 0., 0.],
#         [0., 1., 0.],
#         [0., 0., 1.]])

# 填充指定值
full = torch.full((2, 3), 7.5)      # 形状 2x3，全部填充为 7.5

# 随机数张量（深度学习中权重初始化常用）
rand = torch.rand(2, 3)             # 均匀分布 [0, 1) 之间的随机数
randn = torch.randn(2, 3)           # 标准正态分布（均值0，方差1）
randint = torch.randint(0, 10, (2, 3))  # [0, 10) 之间的随机整数
tensor([[0., 0., 0.],
        [0., 0., 0.]])

使用场景：

  • torch.zeros：初始化偏置项（bias）
  • torch.randn：初始化神经网络权重（配合 Xavier 或 Kaiming 初始化）
  • torch.eye：构建注意力机制中的掩码

1.4 创建等差数列或等间隔序列

# arange：类似 Python 的 range，但返回张量
arange = torch.arange(0, 10, 2)      # start=0, end=10（不含），step=2
print(arange)

# linspace：在指定区间内生成等间隔的 n 个点（包含两端）
linspace = torch.linspace(0, 1, 5)   # 从0到1生成5个等间隔点
print(linspace) 
tensor([0, 2, 4, 6, 8])
tensor([0.0000, 0.2500, 0.5000, 0.7500, 1.0000])

注意：arange 不包含终点，linspace 包含终点。linspace 在生成坐标网格、学习率衰减策略时很常用。

1.5 创建与已有张量相同形状的张量

有时需要创建一个与某个张量形状相同、但内容不同的新张量。

x = torch.randn(3, 4)                # 现有张量

# 创建形状相同但全为0的张量
zeros_like = torch.zeros_like(x)     # 形状 3x4，全0

# 创建形状相同但全为1的张量
ones_like = torch.ones_like(x)       # 形状 3x4，全1

# 创建形状相同但随机数（均匀分布）的张量
rand_like = torch.rand_like(x)       # 形状 3x4，[0,1) 均匀分布

# 创建形状相同但随机数（标准正态）的张量
randn_like = torch.randn_like(x)     # 形状 3x4，标准正态分布

为什么需要 *_like 系列函数？

  • 避免手动写形状元组，减少错误
  • 自动继承原张量的 dtype 和 device（设备类型）

1.6 张量的关键属性

每个张量都携带元信息，必须熟练掌握这些属性的含义。

x = torch.randn(2, 3, 4)             # 创建一个三维张量

# shape：返回张量的形状（元组）
print(x.shape)                       # torch.Size([2, 3, 4])
print(x.size())                      # 与 shape 完全等价

# dtype：数据类型（默认 torch.float32）
print(x.dtype)                       # torch.float32

# device：张量存储在 CPU 还是 GPU
print(x.device)                      # cpu

# numel：元素总数（所有维度乘积）
print(x.numel())                     # 2*3*4 = 24

# dim / ndim：维度数（有几轴）
print(x.dim())                       # 3
print(x.ndim)                        # 3（PyTorch 1.9+ 支持）

# 单个元素的值（当张量为标量时）
scalar = torch.tensor(3.14)
print(scalar.item())                 # 3.14，将标量张量转为 Python 数字
torch.Size([2, 3, 4])

重点理解 shape：

  • torch.Size([2, 3, 4]) 本质上是一个元组，支持索引访问
  • x.shape[0] 返回 2，x.shape[1] 返回 3，x.shape[2] 返回 4

1.7 数据类型（dtype）详解

PyTorch 支持多种数据类型，默认是 float32。深度学习中最常用的几种：

# 常用数据类型
float32 = torch.tensor([1.0, 2.0], dtype=torch.float32)    # 默认，单精度浮点
float64 = torch.tensor([1.0, 2.0], dtype=torch.float64)    # 双精度，更精确但更慢
int64 = torch.tensor([1, 2], dtype=torch.int64)            # 长整型，常用于标签
int32 = torch.tensor([1, 2], dtype=torch.int32)            # 整型
bool_tensor = torch.tensor([True, False])                  # 布尔型

# 在创建时指定 dtype
x = torch.zeros(3, 4, dtype=torch.float64)

# 转换 dtype
x_float = x.float()                  # 转为 float32
x_double = x.double()                # 转为 float64
x_int = x.int()                      # 转为 int32
x_long = x.long()                    # 转为 int64（常用于 CrossEntropyLoss 的标签）

类型选择原则：

  • 模型参数和输入数据：float32（默认，兼顾精度和速度）
  • 分类标签：long（int64）
  • 掩码或索引：bool 或 int

1.8 设备（device）管理

张量可以存储在 CPU 或 GPU 上，跨设备操作会报错，必须统一。

# 查看当前设备
print(torch.cuda.is_available())      # 检查 CUDA 是否可用，返回 True/False

# 在创建时指定设备
cpu_tensor = torch.tensor([1, 2, 3], device='cpu')
gpu_tensor = torch.tensor([1, 2, 3], device='cuda')  # 需要 CUDA 可用

# 动态选择设备（推荐写法）
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
x = torch.randn(3, 4, device=device)

# 张量在不同设备间移动
x_cpu = torch.randn(3, 4)
x_gpu = x_cpu.to('cuda')              # CPU -> GPU
x_back_cpu = x_gpu.to('cpu')          # GPU -> CPU
x_back_cpu2 = x_gpu.cpu()             # 等价写法

重要规则：

  • 两个张量进行运算时，必须在同一设备上
  • 模型和数据必须同时转移到同一设备

1.10 总结

知识点 核心理解
张量的本质 PyTorch 中最基本的数据结构，标量/向量/矩阵/高维数组的统一称呼
torch.tensor() 从列表创建张量，会复制数据，创建独立张量
torch.from_numpy() 从 NumPy 数组创建张量，共享内存，修改会互相影响
torch.zeros / ones / eye / full 创建特殊值张量，用于初始化偏置、权重、掩码等
torch.rand / randn / randint 创建随机张量，randn 常用于权重初始化
torch.arange / linspace 创建等差序列，arange 不含终点，linspace 含终点
*_like 系列函数 创建与已有张量同形状的新张量，自动继承 dtype 和 device
shape / size() 返回张量的形状元组，如 torch.Size([2, 3, 4])
dtype 数据类型，默认 float32；标签用 long，掩码用 bool
device 张量所在设备（CPU/GPU），运算时两方必须在同一设备
numel / dim / ndim 元素总数 / 维度数，快速获取张量规模信息
item() 将标量张量转为 Python 数字
to(device) 张量在 CPU 和 GPU 之间移动的核心方法
